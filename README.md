# 单片机实验：数码管显示4×4矩阵键盘坐标

## 实验目的

按下 4×4 矩阵键盘上任意按键，在 7 段数码管上实时显示该按键的**行列坐标**，格式为 `行-列`。

例如：按下第 2 行第 3 列的按键 → 数码管显示 `2-3`

---

## 硬件平台

| 模块 | 说明 |
|------|------|
| 单片机 | STC89C52 / AT89C52（51 系列） |
| 数码管 | 8 位共阴极动态数码管，位选通过 P2_4/P2_3/P2_2 译码 |
| 矩阵键盘 | 4×4，接 P1 口（行：P1_4~P1_7，列：P1_0~P1_3） |

---

## 文件说明

| 文件 | 作用 |
|------|------|
| `main.c` | 主程序：键盘扫描 → 坐标转换 → 数码管显示 |
| `MatrixKey.c` | 矩阵键盘扫描驱动（返回键码 1~16，无按键返回 0） |
| `MatrixKey.h` | 矩阵键盘头文件 |
| `Delay.c` | 毫秒级软件延时（@11.0592 MHz） |
| `Delay.h` | 延时函数头文件 |

---

## 工作原理

### 键码到坐标转换

```c
行 = (KeyNum - 1) / 4 + 1    // 1~4
列 = (KeyNum - 1) % 4 + 1    // 1~4
```

| 键码 | 行 | 列 | 显示 |
|------|----|----|------|
| 1    | 1  | 1  | 1-1  |
| 2    | 1  | 2  | 1-2  |
| 5    | 2  | 1  | 2-1  |
| 16   | 4  | 4  | 4-4  |

### 数码管显示格式

- 第 1 位：行号（1~4）
- 第 2 位：`-`（段码 0x40）
- 第 3 位：列号（1~4）
