# 单片机实验：数码管显示4×4矩阵键盘坐标

![项目演示](demo.gif)


## 实验目的

按下 4×4 矩阵键盘上任意按键，在 7 段数码管上实时显示该按键的**行列坐标**，格式为 `行-列`。

例如：按下第 2 行第 3 列的按键 → 数码管显示 `2-3`

---

## 硬件平台

| 模块 | 说明 |
|------|------|
| 单片机 | STC89C52 / AT89C52（51 系列） |
| 数码管 | 8 位共阴极动态数码管，位选通过 P2_4/P2_3/P2_2 译码 |
| 矩阵键盘 | 4×4，接 P1 口（行：P1_4~P1_7，列：P1_0~P1_3） |

---

## 文件说明

| 文件 | 作用 |
|------|------|
| `main.c` | C语言主程序：键盘扫描 → 坐标转换 → 数码管显示 |
| `MatrixKey.c` | 矩阵键盘扫描驱动（返回键码 1~16，无按键返回 0） |
| `MatrixKey.h` | 矩阵键盘头文件 |
| `Delay.c` | 毫秒级软件延时（@11.0592 MHz） |
| `Delay.h` | 延时函数头文件 |
| **`main_asm.asm`**| **新增的纯汇编语言实现版本，功能等同于上述所有 C 语言文件的集合** |

## 汇编语言实现说明 (`main_asm.asm`)

为了深入底层，本项目提供了一个功能完全等价的汇编语言版本。

### 1. 结构与寄存器分配
- **R0**：保存当前按键的 `行号 (Row)`。
- **R1**：保存当前按键的 `列号 (Col)`。
- **R2**：用于保存键盘扫描子程序 `MATRIX_KEY` 返回的 `键码 (1~16)`。
- **R6, R7**：用于向数码管显示子程序 `NIXIE` 传递参数（R6 = 位置, R7 = 显示数字）。

### 2. 长跳转指令 (LJMP) 解决地址越界
在原生的汇编代码中，按键矩阵扫描（`MATRIX_KEY`）包含大量的分支。使用短跳转指令 `SJMP`（跳转范围仅为 `-128 ~ +127` 字节）时，由于指令跨度过大会触发 Keil 汇编器的 **`TARGET OUT OF RANGE`** 错误。
**解决方案**：本代码采用 **`LJMP` (长跳转，支持 64KB 全范围)** 跳转到按键去抖与松手检测区域，彻底解决了跨度越界报错问题。

### 3. 如何在 Keil 中编译汇编版本
若想体验汇编版本，需要在 Keil 中进行以下配置：
1. 在左侧 `Project` 资源树中，右键点击现有的 `.c` 文件并选择 **Remove File**（将其移出编译流，但不删除源文件）。
2. 右键 `Source Group 1` -> **Add Existing Files to Group...**，将文件类型（Files of type）选为 `All files (*.*)` 或 `Asm Source file`，添加 `main_asm.asm`。
3. 点击 **Rebuild**，此时 Keil 会调用 A51 汇编器进行编译，生成的 `.hex` 文件即为汇编指令程序。

## 工作原理 (C与汇编通用)

### 键码到坐标转换

```c
行 = (KeyNum - 1) / 4 + 1    // 1~4
列 = (KeyNum - 1) % 4 + 1    // 1~4
```

| 键码 | 行 | 列 | 显示 |
|------|----|----|------|
| 1    | 1  | 1  | 1-1  |
| 2    | 1  | 2  | 1-2  |
| 5    | 2  | 1  | 2-1  |
| 16   | 4  | 4  | 4-4  |

### 数码管显示格式

- 第 1 位：行号（1~4）
- 第 2 位：`-`（段码 0x40）
- 第 3 位：列号（1~4）
